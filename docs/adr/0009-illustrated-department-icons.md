# 科室图标改为多色插画图标

科室图标从「单色线性描边」改为「实心色块 + 同色深一档描边 + 小面积高光」的多色插画图标，每个科室固定一个色相。为此在动作色与语义色之外新增第三个颜色角色「插画色」，只用于图标内部，并只出现在首页科室宫格与后台科室管理的列表/选择器。

背景：用户先要求「不要 emoji」，图标被做成单色线性；随后要求「上色」，项目试了低饱和每科一色与高饱和每科一色两版，都是给同一套线稿换颜色，被要求回退；用户再澄清「更多彩的 icon 类似于给漫画上色」。真正要的是插画形体，不是换颜色的线稿。

## 考虑过的方案

- 单色相双色调（每科一个色相，仍只有一个颜色）：本质上还是单色，不满足需求。
- 共享调色板、按部位分配颜色：科室之间失去颜色识别度。
- 换用现成彩色图标库：重新引入「风格不受控」的问题，正是 emoji 被换掉的原因。
- 保留线性图标只加彩色底衬：已试过，用户明确否掉。

## 决定

- 图标重绘为「线稿 + 填色」结构：主体实色、描边取主色加深、内层一档浅色，十个图标共用象牙白 `#fcf0e4` 作小面积高光。
- 颜色是图标的一部分，不再跟随 `currentColor`，也不能靠 CSS 换色。
- 颜色只存前端 `utils/deptIcons.js`，不进数据库：颜色是设计决定而不是业务数据，避免管理员逐个配出十种不协调的颜色。
- 图标 32px、窄屏三列；不加底块。图标直接落白卡面，底块加描边卡片会读成「一格套一格」。
- 使用范围：首页科室宫格与后台科室管理的列表/选择器；医生卡片、预约详情等处的科室仍为纯文字。

## 后果

- `docs/design.md` 里「图标是名称的视觉锚点，不是第二个品牌色」这条被改写为「图标属于插画层，插画色不参与动作与状态语义」。
- 插画色必须与动作色、六种语义色拉开距离，防止彩色图标被误读为主按钮或业务状态。
- 高对比模式下彩色全部失效，因此显式降级为单色描边（`CanvasText`），保住形状。

未从登录页吉祥物插画取色。吉祥物只有 hue 0–30 的暖色（奶油、浅肤、棕、珊瑚），严格取色会得到一个全暖、彼此很近的调色板，与「更多彩」冲突；最终改为在语义与对比度约束下搜索色相，只保留了象牙白作为高光色。

## 视觉评审的修正（四轮，6 → 7 → 8 → 8）

独立评审者无项目上下文，只见截图与约束。逐轮处理：

1. **6 分**。「十格四种无彩」一半是取证 bug：注入只覆盖首屏六格，展开后 Vue 新渲染的四格仍是单色组件。其余属实并已改：提高主色用量（口腔、眼科从近白改为整块主色）、按墨迹归一尺寸、重排撞色、删掉口腔内部像裂纹的曲线。影像曾加浅色底衬承托四角线。
2. **7 分**。线重只统一了源属性、实际渲染在 1.0–1.5px 浮动；影像的 2.2 是漏改；影像底衬读成嵌套底块；急诊红心读成「收藏」。处理：线宽按 `V/32` 反向补偿；影像去底衬只留四角框与实心镜头；急诊改急救箱。
3. **8 分**。皮肤与疫苗同色带（色差 15.3），疫苗偏小且原因在于斜放 45° 时外接框长边由对角线决定。处理：按外接框几何均值 `sqrt((w+pad)*(h+pad))` 归一，对齐观感面积而非包围框；疫苗改橄榄黄绿；外科微调；急救箱提手线宽并入 1.4。
4. **8 分**。评审纠正了此前两处陈述错误：外科/口腔色差实际由 26.2 降到 23.2（不是提高）；旧疫苗品红与品牌红的 ΔE 是 61.5（不近），真正冲突的是它和皮肤紫。

## 已知遗留

- 疫苗用橄榄黄绿而非直觉上的医疗色，是为了同时避开皮肤紫与红色带。180px 缩略图下它与营养绿（第 3 行相邻）并成一个色族；实机 32px 可辨，且有形状与名称兜底。若要彻底消除，需要调整首页科室排序，让这两个绿不相邻。
- `forced-colors` 降级写了规则但未在真实系统高对比模式下验证。
- 本轮不做动效。
