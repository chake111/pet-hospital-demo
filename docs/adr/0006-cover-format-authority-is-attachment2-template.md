# 论文封面以学校规范和论文模板为基准

- 格式先按附件1规范，再按修订版论文模板；学长参考件只补充两者未规定的细节。理由：参考论文可能包含排版缺陷，不能覆盖学校明确要求。
- 保留“学生姓名”“指导教师姓名”“指导教师职称”等标签，个人字段值与日期不随参考件替换。理由：参考件只能提供版式参考，不能改变提交人的身份信息。
- 引用“附件2”时写清是论文模板还是开题表。理由：两份材料编号相同，标签与排列要求却不同。
- 封面调整同步维护 `build.cjs` 的 `COVER_FIELDS`、封面表函数及相关校验；日期来自 `docxstyle.cjs`。理由：只改导出的 Word 文件会在下次生成时丢失，生成器与校验断言也必须保持一致。
- 当前字段表保留 2500 / 5046 twips 两列；更改列宽或空段后复核渲染。理由：标签可用宽度受单元格边距影响，仅切换自动布局不能保证长标签不折行。
- 封面段落的 `snapToGrid=0` 由 `docxpost.py` 的 `cover_no_snap` 注入。理由：当前生成路径通过 XML 后处理控制网格，不能把未输出到 XML 的构造参数当作生效证据。
- 最终分页与折行用 Word 导出 PDF 核对；使用 LibreOffice 的流水线还应检查两种引擎差异。理由：两种引擎对网格和字体的处理不同，历史页数或未排版的 COM 统计值不能替代当前成品验收。

代码依据：`tools/thesis-docx/build.cjs`、`docxstyle.cjs`、`docxpost.py`、`verify_docx.py`。本条只规定格式来源与生成流程，不代表本次重新验收了论文成品。
